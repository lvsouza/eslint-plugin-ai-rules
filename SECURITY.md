# Security Policy

## Supported versions

Security fixes are provided for the latest published minor version.

| Version | Supported |
| ------- | --------- |
| 0.4.x   | Yes       |
| < 0.4   | No        |

## Reporting a vulnerability

Please do not open a public issue for security vulnerabilities.

Send a private report to **ls18017@gmail.com** with:

- a description of the issue;
- steps to reproduce;
- affected versions;
- any suggested fix or mitigation.

You can expect an initial response within a few business days. Confirmed issues will be fixed in a new release and documented in the changelog when appropriate.
